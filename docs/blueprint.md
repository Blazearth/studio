# **App Name**: StocKaro MVP

## Core Features:

- Home Screen: Display a welcome message with a tagline and navigation buttons to the courses page and mentorship options.
- Courses Page: Display a free beginner course card with a course description and a button to start the course, which opens an embedded YouTube video and a short quiz.
- Quiz and Certificate: Show 3 multiple-choice questions after the course video, display a 'Congratulations!' screen upon correct completion, and auto-generate a mock certificate.
- Feedback Collection: Collect user feedback, including name, email, rating (1–5 stars), and suggestions, through a feedback form.

## Style Guidelines:

- Primary color: A calming blue (#3498db) to inspire trust and learning.
- Secondary color: A clean white (#ffffff) for a modern and readable interface.
- Accent: A vibrant green (#2ecc71) to highlight important actions and success moments.
- Clear and readable typography optimized for both mobile and desktop viewing.
- Simple and intuitive icons to represent different sections and actions.
- A responsive layout that adapts seamlessly to different screen sizes, ensuring a consistent user experience.
- Subtle animations and transitions to provide feedback and enhance the user experience.
